# Métiers et populations de Tanares

Cette documentation décrit les activités de Tanares, leur organisation en métiers, les populations qui les exercent et les moyens de nourrir ces habitants. Elle transmet le scénario médiéval fantastique calculé et ses références : **66 bases, 234 spécialisations, 33 généralistes, 118 profils**, avec fonctions et compétences propres à chaque branche.

**Les activités peuvent être attestées ; la hiérarchie, les compétences détaillées et les pourcentages sont proposés.** L’équilibre énergétique calculé dépend des terres, des transports et des capacités magiques retenus. Les limites et les crises restent visibles.

## Lire l’arbre

![Les filières regroupent les bases puis leurs activités terminales](Figures/arbre-familles.svg)

Une base est une famille de procédés, pas un individu supplémentaire. Une personne compte dans une seule branche principale. Les grades d’apprenti, compagnon ou maître, les classes de personnage, les titres, les activités secondaires et la propriété traversent cette organisation sans devenir de nouveaux habitants.

## Lire une valeur

A signifie activité ou mécanisme **attesté**, D **déduit**, P **proposé**. Les pourcentages restent P même à côté d’une activité A. Une valeur inconnue n’est pas zéro ; un zéro de scénario ne signifie pas interdiction universelle. Les 13 régions chiffrées totalisent 11 081 000 habitants ; leurs villes sont incluses, pas additionnées une deuxième fois.
