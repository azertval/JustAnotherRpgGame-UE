# Tableaux complets des professions

[Accueil](../README.md) · [Arbre des métiers](../arbre-metiers.md)

Chaque CSV contient 267 branches, deux statuts, les deux dénominateurs, les contributions des strates sociales, les références et le raisonnement local. Les CSV sont encodés en UTF-8 avec séparateur point-virgule. Les effectifs décimaux sont attendus dans un scénario, pas un recensement d’individus.
